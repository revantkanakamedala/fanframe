# FanFrame

FanFrame is a sports fan engagement and event-memory app designed to help fans capture live game reactions, photos, videos, and personal recaps in one place.

## Project Overview

The idea started around a simple problem: fans capture a lot of content during live events, but those memories are usually scattered across camera rolls, social media posts, and messages.

FanFrame creates a structured experience where a user can identify the game they are attending or watching, capture moments, react to key plays, and save a complete game recap.

## Core Experience

- Discover or confirm a live game
- Capture photos and short videos
- Add reactions and captions
- Build a game recap
- Save memories to an Event Passport
- Review previous events
- Track game-specific moments and reactions
